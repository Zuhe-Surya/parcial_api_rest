Guia rapida

Como usar la API

Registrate, obtene tu token y envialo en las peticiones protegidas.

01

Registrarse

Crea tu cuenta con usuario y contrasena.

POST/api/auth/register
curl -X POST http://localhost:3000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"usuario1","password":"pass1234"}'
02

Obtener token

Inicia sesion y copia el token de la respuesta.

POST/api/auth/login
curl -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"usuario1","password":"pass1234"}'
03

Usar el token

Agrega el header Authorization en peticiones protegidas.

POST/api/productos
TOKEN="tu-token-aqui"
curl -X POST http://localhost:3000/api/productos \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"nombre":"Laptop","precio":2500000,"categoria":"ID"}'

Validaciones

Reglas de negocio

Restricciones que el servidor aplica antes de persistir datos.

409

Nombre de categoria unico

No pueden existir dos categorias con el mismo nombre en la base de datos.

400

Categoria debe existir

El campo categoria de un producto debe referenciar una categoria real.

400

ObjectId valido

El ID de categoria se valida como ObjectId de MongoDB antes de la consulta.

400

Nombre obligatorio

El campo nombre de producto no puede estar vacio ni ausente.

400

Precio numerico

El campo precio es requerido y debe ser un numero valido.

401/403

JWT requerido en POST

Crear categorias y productos exige token valido. Sin token: 401, invalido: 403.

Proteccion

Seguridad

Capas que protegen la API y los datos de los usuarios.

JWT firmado

Tokens firmados con JWT_SECRET. Un token alterado o vencido retorna 403.

bcrypt

Las contrasenas se almacenan como hash y nunca se exponen en respuestas.

Middleware verifyToken

Intercepta las rutas protegidas antes de pasar al controlador.

Validacion de IDs

Todos los ObjectIds se validan con Mongoose antes de consultar MongoDB.

Variables de entorno

MONGO_URI y JWT_SECRET viven en .env y nunca en el codigo.

MongoDB Atlas

Base de datos en la nube con cifrado en transito y autenticacion por usuario.
